# Skill: Frontend Design

## Descripción
Esta skill proporciona plantillas y guías para crear páginas web modernas y responsivas. Incluye:

- Estructura HTML5 semántica
- CSS con diseño responsive (grid, flexbox)
- Paletas de colores accesibles
- Tipografía legible
- Optimización para dispositivos móviles

## Plantillas Predefinidas

### Página de Tienda de Ropa (ModaLuz)
- Header con logo y menú
- Secciones: Inicio, Productos, Sobre Nosotros, Contacto
- Diseño con gradiente de fondo
- Tarjetas de productos con imágenes y precios
- Footer con información de contacto

### Plantilla Minimalista
- Layout simple y limpio
- Tipografía sans-serif
- Colores neutros con acentos
- Responsivo para móviles
